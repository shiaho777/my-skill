# SVG 图的设计和验证

## 选合适的视觉形式

| 读者的问题 | 形式 | 优先保留的信息 |
|---|---|---|
| 系统由什么组成 | 分层图或组件图 | 责任边界、入口、依赖方向，箭头标数据或调用 |
| 操作如何推进或失败 | 流程图、时序图或泳道图 | 起点、分支条件、执行者、失败和恢复路径 |
| 数据差异有多大 | 表格、水平条形图或趋势图 | 单位、刻度、基线、样本范围和来源 |
| 产品实际长什么样 | 应用截图 | 真实状态、清楚的裁剪、能复现的上下文 |

## 画法

- 先写一句这张图要帮助读者判断什么，再组织节点、标签和阅读方向。删掉与它无关的装饰，避免箭头穿过标签。
- 用 `viewBox` 保持可缩放。选一个系统字体栈、少数字号和一致间距。检查目标文档的实际嵌入宽度，节点多时优先拆图或缩短标签。
- 使用有对比度的前景和背景。颜色和线型有固定语义，并配合文字或图例。深浅主题都可读的独立浅底或深底可作为可移植选择。
- 条形图的长度按带单位的统一线性比例计算，从零起。数量级差异较大时保留精确值标签，或改用表格及清楚标记的对数图。估算值额外标注并在图注或正文给出推导。
- 保持 SVG 自包含，使用简单形状、文本和路径。给图写清楚的替代文本，并把不可丢失的数据或结论放到相邻正文。

## 验收

在目标平台打开实际文档，检查最窄常用宽度是否裁剪、箭头和标签是否清楚、图注和数值是否对应。随 Skill 附带的验证器可以查 XML、常见脚本标记、本地 SVG 引用和孤立文件。
